# Security policy

## Reporting a vulnerability

Please report security problems privately by email to
**support@apexaiofficial.com**, not in a public issue. Include:

- what you found and its impact,
- steps to reproduce (a minimal script is ideal),
- the `apexai-shop` version and Python version.

Never include a real API token in a report. If a token may have been exposed,
revoke it first with `/apitoken` in the private chat with your store's bot.

We acknowledge reports within a few working days and keep you informed until
the issue is resolved.

## Supported versions

Security fixes go into the latest release.

| Version | Supported |
| --- | --- |
| 0.1.x | yes |

## Scope

This repository contains the public Python client for the Shop Bot merchant
API. Problems with the API itself or with a store can be reported to the same
address.
